# 🧮 VinhMathToolbox

Welcome to **VinhMathToolbox**, a high-performance C++ mathematical toolkit designed to solve complex math problems in the blink of an eye! 🚀

## 🌟 Introduction
This project is a long-term development journey. Moving from Scratch blocks to C++, this toolbox leverages the speed of compiled code and smart algorithms to handle numbers and logic instantly.

## 🛠️ Features (Version 1.0 & 1.1)
* **Prime Checker:** Uses an optimized $O(\sqrt{N})$ loop with a step of 6 to check massive numbers (up to hundreds of billions) in less than 1 millisecond.
* **GCD Finder:** Implements the famous Euclidean algorithm using continuous modulo operations for lightning-fast results.
* **Chicken & Dog Solver:** Automatically solves the classic Vietnamese puzzle (Finding two numbers given the Total and Hypothetical assumption) using integer arithmetic.
